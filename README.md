### **03 ETL Pipeline with Unit Tests** 

Stack: Python, requests, pandas, pytest (Week 3 skills) 

**Overview** 

A complete, tested Extract-Transform-Load pipeline. Fetches live data from a public REST API, transforms using pandas, writes output to CSV. Transform logic covered by a pytest test suite. 

**Learning Objectives** 

    • Structure a Python project as a package with modules 
    • Make HTTP API calls and parse JSON with error handling 
    • Apply multi-step pandas transformations with testable functions 
    • Write a complete pytest suite with fixtures and parametrized tests 
    • Use generators for memory-efficient processing 
**What to Build** 

    16. Create structure: etl_project/ with extractor.py, transformer.py, loader.py, and tests/test_transformer.py. 
    17. extractor.py: fetch_posts(url, timeout=10) and fetch_users(url). Handle ConnectionError and Timeout. 
    18. transformer.py: add_word_count(df), categorize_post(df), merge_with_users(), filter_posts(df, 
    min_words=30). 
    19. loader.py: save_to_csv(df, output_path) creating directory if missing. 
    20. main.py: orchestrate steps, print summary, time total execution. 
    21. tests/: tests for add_word_count, categorize_post (5+ parametrized), filter_posts, and a shared fixture. 
    22. Add conftest.py with a shared sample posts DataFrame. 
**Deliverables** 

    • Full etl_project/ folder with all 4 modules + tests/ 
    • output/etl_result.csv generated by running main.py 
    • All pytest tests passing (include pytest -v output in a comment) 
    • requirements.txt listing all dependencies 
**Evaluation Criteria** 

    • Pipeline runs end-to-end with python main.py 
    • All pytest tests pass including parametrized tests 
    • Transformations in separate functions 
    • API errors handled gracefully 
    • Code is clean, typed, and documented
